> **日期**: 2026-07-15

> **测试人员**: zglstudylinux  
> **测试工具**: 万用表、跳线

## 1. 测试目的

验证 BT892X 的 GPIO 基本功能：
- **输出模式**: 引脚能否正确输出高/低电平
- **输入模式**: 引脚能否正确读取外部电平（含内部上拉）
- **GPIO 控制寄存器**: 验证 DIR/DE/FEN/PU 等寄存器的实际行为

---

## 2. 测试原理

### 2.1 GPIO 寄存器（参考手册 §3.2）

BT892X 每个 GPIO Port（PA/PB/PE/PF/PG）都有以下控制寄存器：

| 寄存器 | 功能 | 说明 |
|--------|------|------|
| `GPIOxDIR` | 方向控制 | 0=输出, 1=输入（默认 0xFF 全输入） |
| `GPIOxDE` | 数字使能 | 0=模拟IO, 1=数字IO（默认 0xFF） |
| `GPIOxFEN` | 功能映射使能 | 0=GPIO模式, 1=功能IO模式（默认 0xFF） |
| `GPIOxPU` | 10K 上拉 | 1=使能（输入模式下有效） |
| `GPIOxPD` | 10K 下拉 | 1=使能 |
| `GPIOxSET` | 置位寄存器 | 写1对应位输出高 |
| `GPIOxCLR` | 清除寄存器 | 写1对应位输出低 |
| `GPIOx` | 数据寄存器 | 读=输入状态, 写=输出状态 |

### 2.2 GPIO 配置要点

要将引脚配置为 **GPIO 输出**：
1. `DIR=0`（输出方向）
2. `DE=1`（数字 IO 使能）
3. `FEN=0`（GPIO 模式，关闭功能映射）

要将引脚配置为 **GPIO 输入（带上拉）**：
1. `DIR=1`（输入方向）
2. `DE=1`（数字 IO 使能）
3. `FEN=0`（GPIO 模式）
4. `PU=1`（10K 上拉使能）

## 3. 硬件连接

| 引脚 | 功能 | 连接 |
|------|------|------|
| **PE4** | GPIO 输出 | 万用表红表笔（测电压） |
| **PF0** | GPIO 输入（10K 上拉） | 通过跳线可选连到 PE4 |
| **GND** | 参考地 | 万用表黑表笔 |

```
BT892X Board
+----------+
|          |
|  PE4 ----+-------> 万用表 (+)
|          |         [可选跳线到 PF0]
|  PF0 ----+
|          |
|  GND ------------> 万用表 (-)
|          |
+----------+
```

## 4. 测试步骤

### 4.1 编译与下载

1. 在 Code::Blocks 中将 `smart_mini/test/gpio_test.c` 添加到工程
2. 确保 `smart_mini/test/` 目录在编译器 include 路径中（或已在工程设置中配置）
3. 编译生成 `app.dcf`
4. 用 Downloader 工具下载到 BT892X 开发板
5. 打开串口助手（波特率 1500000），观察 printf 输出

### 4.2 输出测试（不接跳线）

1. 万用表调到直流电压档（20V 量程）
2. 红表笔接 PE4，黑表笔接 GND
3. 观察串口输出和万用表读数：
   - 串口打印 `PE4=HIGH` 时，万用表应显示 **≈3.3V**
   - 串口打印 `PE4=LOW` 时，万用表应显示 **≈0V**
4. 此时 PF0 因上拉应始终为 HIGH（串口显示 `PF0=1`）

### 4.3 输入测试（接跳线 PE4↔PF0）

1. 用跳线连接 PE4 和 PF0
2. 观察串口输出：
   - PE4=HIGH 时，PF0 应显示 `1`（`JUMPER OK - follows PE4`）
   - PE4=LOW 时，PF0 应显示 `0`（`JUMPER OK - follows PE4`）

### 4.4 附加测试（PF0 接地）

1. 去掉跳线
2. 用跳线将 PF0 直接接到 GND
3. PF0 应显示 `0`（上拉被强制拉低）

## 7. 关键寄存器配置汇总

```c
// PE4 → GPIO 输出
GPIOEDIR &= ~BIT(4);     // 输出模式
GPIOEDE  |=  BIT(4);     // 数字 IO
GPIOEFEN &= ~BIT(4);     // GPIO 模式（关闭功能映射）

// PF0 → GPIO 输入 + 10K 上拉
GPIOFDIR |=  BIT(0);     // 输入模式
GPIOFDE  |=  BIT(0);     // 数字 IO
GPIOFFEN &= ~BIT(0);     // GPIO 模式
GPIOFPU  |=  BIT(0);     // 10K 上拉

// 输出控制
GPIOESET = BIT(4);       // PE4 输出高
GPIOECLR = BIT(4);       // PE4 输出低

// 读取
u32 pe4 = (GPIOE >> 4) & 1;
u32 pf0 = (GPIOF >> 0) & 1;
```
