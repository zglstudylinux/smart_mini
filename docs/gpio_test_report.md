## 1. 测试目的

验证 BT892X 的 GPIO 基本功能：
- **输出模式**: 引脚能否正确输出高/低电平
- **输入模式**: 引脚能否正确读取外部电平（含内部上拉）
- **GPIO 控制寄存器**: 验证 DIR/DE/FEN/PU 等寄存器的实际行为

---

## 2. 测试原理

### 2.1 GPIO 寄存器（参考手册 §3.2）

BT892X 每个 GPIO Port（PA/PB/PE/PF/PG）都有以下控制寄存器：

| 寄存器 | 功能 | 说明 |
|--------|------|------|
| `GPIOxDIR` | 方向控制 | 0=输出, 1=输入（默认 0xFF 全输入） |
| `GPIOxDE` | 数字使能 | 0=模拟IO, 1=数字IO（默认 0xFF） |
| `GPIOxFEN` | 功能映射使能 | 0=GPIO模式, 1=功能IO模式（默认 0xFF） |
| `GPIOxPU` | 10K 上拉 | 1=使能（输入模式下有效） |
| `GPIOxPD` | 10K 下拉 | 1=使能 |
| `GPIOxSET` | 置位寄存器 | 写1对应位输出高 |
| `GPIOxCLR` | 清除寄存器 | 写1对应位输出低 |
| `GPIOx` | 数据寄存器 | 读=输入状态, 写=输出状态 |

### 2.2 GPIO 配置要点

将引脚配置为 **GPIO 输出**：
1. `FEN=0`（GPIO 模式，关闭功能映射）
2. `DE=1`（数字 IO 使能）
3. `DIR=0`（输出方向）
4. 通过 `SET`/`CLR` 寄存器控制输出电平

将引脚配置为 **GPIO 输入（带上拉）**：
1. `FEN=0`（GPIO 模式）
2. `DE=1`（数字 IO 使能）
3. `DIR=1`（输入方向）
4. `PU=1`（10K 上拉使能）

## 4. 测试步骤

### 4.1 编译与下载

1. 在 Code::Blocks 中将 `smart_mini/test/gpio_test.c` 添加到工程
2. 编译生成 `app.dcf`
3. 用 Downloader 工具下载到 BT892X 开发板
4. 打开串口助手（波特率 1500000），观察 printf 输出

### 4.2 输出测试

1. 逻辑分析仪 CH1 接 PE4
2. 观察 PE4 电平每 1 秒翻转一次
3. 万用表直流电压档验证：HIGH ≈3.3V, LOW ≈0V

### 4.3 输入测试（跳线 PE4 ↔ PE5）

1. 用跳线连接 PE4 和 PE5
2. 观察串口输出：
   - PE4=HIGH 时，PE5 读取为 1
   - PE4=LOW 时，PE5 读取为 0（跟随 PE4 变化）

## 6. 调试经验总结

### 6.1 引脚选择注意事项

| 端口 | 输出 | 输入 | 备注 |
|------|:--:|:--:|------|
| **PORTE** | ✅ | ✅ | 无 UART 冲突，推荐使用 |
| **PORTF** | ✅ | ⚠️ | 输出正常，输入读取不可靠（原因待查） |
| **PORTA** | ❌ | — | 受 `FUNCMCON0` UART 映射影响，PA4 输出不翻转 |

### 6.2 关键踩坑

1. **`FUNCMCON0 = (7<<12)|(3<<8)` 会清掉 UART1 映射位**：`main.c` 中使用 `=` 直接赋值而非 `|=`，导致 UT1TXMAP/UT1RXMAP 被意外清零，可能影响 PORTA 引脚的 GPIO 功能。建议后续改为 `FUNCMCON0 = (FUNCMCON0 & 0xFF000000) | (7<<12) | (3<<8)` 以保留高位。

2. **FEN 必须在 DIR 之前配置**：先将 `FEN=0` 关闭功能映射切换到 GPIO 模式，再设置方向和上下拉。

3. **PORTF 输入异常**：PF0 作为输入时无法正确读取引脚电平（始终为 1），即使引脚电压被拉到 0V。PORTF 输出功能正常。根因未完全定位，后续测试中如需输入功能，优先使用 PORTE。

## 7. 最终寄存器配置

```c
// PE4 → GPIO 输出
GPIOEFEN &= ~BIT(4);     // GPIO 模式
GPIOEDE  |=  BIT(4);     // 数字 IO
GPIOEDIR &= ~BIT(4);     // 输出方向

// PE5 → GPIO 输入 + 10K 上拉
GPIOEFEN &= ~BIT(5);     // GPIO 模式
GPIOEDE  |=  BIT(5);     // 数字 IO
GPIOEDIR |=  BIT(5);     // 输入方向
GPIOEPU  |=  BIT(5);     // 10K 上拉

// 输出控制
GPIOESET = BIT(4);       // PE4 输出高
GPIOECLR = BIT(4);       // PE4 输出低

// 读取输入
u32 pe5 = (GPIOE & BIT(5)) ? 1 : 0;
```

## 8. 结论

✅ **GPIO 测试通过**。BT892X 的 GPIO 输出和输入功能在 PORTE 上验证正常。寄存器配置方式（FEN→DE→DIR→PU/SET/CLR）正确。后续测试将优先使用 PORTE 引脚（PE4/PE5/PE6/PE7）。
